# 01｜项目概述：即时战斗与卡牌策略结合

## 核心玩法

本项目将即时动作战斗与时停卡牌管理结合。

玩家在即时战斗中，通过移动、瞄准及卡牌技能释放应对敌人；进入时停后，可以调整手牌、抽取新卡及融合强化现有技能，再返回即时战斗。

### 核心体验目标

**即时战斗：** 强调移动操作、攻击时机、技能范围及敌人应对。

**时停管理：** 提供观察局势、调整技能组合及优化当前战斗配置的空间。

**卡牌表现：** 通过不同的施法方式、攻击形态、目标选择、位移及状态效果，使各类卡牌形成明确的操作体验。

### 我的负责范围

- 战斗状态切换及可执行操作规则
    
- 玩家移动、选卡、瞄准与释放交互
    
- 卡牌技能的选取方式、释放流程和战斗表现
    
- 攻击、防御、位移、增益及减益效果的执行逻辑
    
- 技能范围预览、命中反馈与异常处理
    
- 战斗系统程序需求及功能验收规则
    

**协作边界：** 伤害倍率、属性成长、卡牌冷却与资源消耗数值由数值策划配置和维护；卡牌奖励及局外成长由战斗外系统负责。

# 02｜核心战斗循环：即时战斗与时停管理

## 战斗流程

**进入战斗 → 免费抽取初始手牌 → 初始时停 → 即时战斗 → 自由进入时停 → 抽牌/换牌/强化 → 返回战斗 → 战斗结算**

### 即时战斗阶段

玩家使用WASD移动，选择卡牌并释放技能。

技能成功释放后进入冷却或消耗状态。

有效伤害及有效格挡事件可以提供回路值，用于支持后续卡牌管理。

### 时停阶段

玩家按空格进入时停，战斗世界冻结。

此时允许三类操作：

|操作|规则|对战斗的作用|
|---|---|---|
|抽牌|消耗回路值，从抽牌堆获取卡牌|扩展当前技能选择|
|换牌|以抽牌区卡牌替换指定手牌|调整当前可用技能|
|强化|消耗同名副卡，提升手牌强化档位|改变技能效果和表现形式|

时停结束时，抽牌区剩余卡牌进入弃牌堆。

### 关键设计处理

**自由时停：** 玩家可以自由进入时停，卡牌管理行为通过回路值约束。

**战斗时间冻结：** 时停期间同步冻结敌人AI、投射物、技能冷却及持续状态计时。

**临时强化：** 同名卡牌融合只影响当前战斗，后续战斗重新按牌组数据初始化。

# 03｜战斗交互：从选卡到技能命中

## 输入设计

|输入|行为|
|---|---|
|WASD|地面移动|
|数字键1—5|选择对应卡槽|
|鼠标移动|选择方向、位置或目标|
|鼠标左键|确认并释放技能|
|鼠标右键|取消技能预览|
|空格|切换时停|
|Esc|打开普通暂停|

## 技能释放流程

**选卡 → 技能预览 → 瞄准 → 确认 → 合法性校验 → 技能前摇 → 效果生效 → 冷却/消耗**

### 1. 预览阶段

选择卡牌后，根据技能类型显示对应的方向、范围、目标或位移路径。

预览过程中允许玩家移动，范围跟随角色位置更新。

### 2. 确认阶段

玩家通过鼠标左键确认。

系统检查角色状态、卡牌冷却、目标有效性和施法范围。

确认后锁定技能参数，进入施法阶段。

### 3. 施法阶段

所有主动技能共享0.22秒公共施法锁，并具有独立的技能前摇配置。

施法期间限制其他技能释放，防止多技能输入冲突。

### 4. 生效阶段

技能到达效果执行时点后进行生效校验。

成功启动后执行对应技能效果，并开始冷却或消耗卡牌。

### 异常交互处理

|场景|处理|
|---|---|
|目标超出距离|显示无效范围，禁止释放|
|位移终点被阻挡|提示非法落点|
|角色处于施法锁|拒绝新的释放请求|
|技能生效前目标失效|终止释放，不启动冷却|
|追踪弹攻击未完成|反馈未完成攻击，返还CD|

**设计重点：** 使技能释放过程具有明确的视觉预期、可理解的失败反馈及统一的操作响应。

# 04｜技能表现：不同卡牌的战斗行为设计

本系统包含攻击、防御、位移、一次性增益、减益五类卡牌，共22种技能。

我主要负责将技能配置转化为具体的战斗行为，明确技能如何选取目标、何时生效、怎样表现以及如何反馈结果。

## 代表性技能案例

### 案例A：地震｜多波次范围攻击

**表现目标：** 通过连续向外扩张的冲击波体现技能的范围压制效果。

执行逻辑：

1. 玩家释放后进入技能前摇。
    
2. 以角色为中心生成第一圈冲击波。
    
3. 后续冲击波按0.22秒间隔向外扩张。
    
4. 每一波分别执行范围检测与伤害结算。
    
5. 强化档位可以改变波次数量及覆盖范围。
    

表现要求：

- 冲击波范围与实际命中区域一致。
    
- 不同波次具有明确的时间顺序。
    
- 每次命中独立触发受击反馈。
    
- 视觉表现不能额外产生重复伤害。
    

### 案例B：追踪弹｜锁定目标与投射物追踪

**表现目标：** 建立清晰的目标锁定、发射、追踪与命中反馈。

执行逻辑：

1. 通过鼠标选择有效敌方目标。
    
2. 释放时生成追踪投射物。
    
3. 投射物向目标持续移动。
    
4. 命中时执行伤害结算。
    
5. 目标提前死亡或丢失且攻击无法完成时，终止投射物并返还本次CD。
    

表现要求：

- 显示当前锁定目标。
    
- 投射物运动与逻辑目标保持一致。
    
- 攻击未完成时提供明确反馈。
    

### 案例C：闪现｜落点选择与位移反馈

**表现目标：** 让玩家在释放前准确理解可到达的位置。

执行逻辑：

1. 显示最大可选位移范围。
    
2. 鼠标移动时更新目标落点。
    
3. 对目标落点进行玩家碰撞体检测。
    
4. 合法时允许释放。
    
5. 释放后直接移动至目标位置。
    

表现要求：

- 有效与无效落点采用不同颜色反馈。
    
- 展示位移起点与目标终点。
    
- 落点必须能够完整容纳角色碰撞体。
    
- 强化后的距离与附加效果同步更新预览。
    

### 案例D：燃烧｜区域效果与持续状态

**表现目标：** 清晰区分地面区域与目标身上的持续燃烧状态。

执行逻辑：

1. 玩家选择燃烧区域中心。
    
2. 在指定位置生成持续存在的燃烧区域。
    
3. 敌人进入区域后附着燃烧状态。
    
4. 燃烧状态按照配置周期执行伤害。
    
5. 区域与附着状态分别计时。
    

表现要求：

- 地面区域展示持续存在范围。
    
- 敌人附着状态时显示状态反馈。
    
- 状态伤害与数值反馈同步。
    
- 区域结束及附着状态结束分别处理表现。

# 05｜战斗规则：从技能效果到统一判定

## 统一技能分类

不同卡牌通过统一的技能框架执行。

|技能类型|核心行为|关键判定|
|---|---|---|
|攻击|方向攻击、范围攻击、追踪投射物|命中区域、多段结算|
|防御|护盾、减伤、闪避、反伤、免死|受击事件与防御优先级|
|位移|冲刺、后撤、闪现、跳跃|路径碰撞、目标落点|
|一次性增益|属性提升、冷却缩减|效果生效与使用后消耗|
|减益|持续伤害、减速、定身、伤害削弱|状态附着、持续与结束|

## 统一承伤结算

采用以下优先级：

**无敌 → 护盾 → 减伤 → 生命伤害**

特殊技能按照单独的事件顺序处理。

例如：

- 闪避对多段攻击逐段判定。
    
- 反射场依据敌方面板伤害先处理反伤，再处理减伤。
    
- 感电追加伤害不再次触发感电，防止递归。
    
- 燃烧的周期伤害按实际有效结算帧发送伤害事件。
    

## 被动技能

闪避与不屈仅在手牌区生效。

- 被动牌占用手牌槽。
    
- 进入手牌时注册触发条件。
    
- 离开手牌时停止后续触发资格。
    
- 通过统一受击事件执行判定。
    

## 设计目的

通过明确技能触发时机、执行顺序、效果生命周期及异常分支，让不同技能共用稳定的底层规则，降低技能组合产生逻辑冲突的风险。

# 06｜研发落地：配置驱动与跨岗位协作

## 技能配置结构

面向程序的单卡配置包含：

|配置模块|主要内容|
|---|---|
|卡牌身份|ID、类别、品质|
|触发规则|主动/被动、触发条件|
|目标选取|方向、地点、目标、自身|
|技能范围|距离、形状、碰撞规则|
|时间节点|公共施法锁、前摇、生效点、冷却、持续时间|
|效果执行|伤害、状态、位移、增益、减益|
|强化行为|S/P/T对应的技能变化|
|表现资源|动画、特效、音效、UI反馈|

数值字段采用外部配置，由数值策划维护。

战斗策划侧重点为技能行为与效果执行的对应关系，以及技能规则在实际战斗中的正确呈现。

## 模块协作

**程序：** 对接状态机、卡牌运行时数据、技能执行、命中检测、角色控制及效果事件。

**美术与动画：** 对接技能预览、动作节点、投射物、范围特效及状态反馈。

**UI：** 对接卡槽状态、技能冷却、选中反馈、时停管理和技能不可用提示。

**数值策划：** 对接伤害、持续时间、冷却、资源消耗及S/P/T数值配置。

**关卡及战斗外系统：** 对接战斗结果、牌组数据、奖励和局外融合系统。

## 功能验收重点

- 时停正确冻结并恢复战斗时间。
    
- 技能预览与实际命中范围保持一致。
    
- 非法目标及落点不能释放。
    
- 公共施法锁能够阻止冲突输入。
    
- 多段攻击独立结算且不重复触发。
    
- 被动牌随手牌状态正确启用和关闭。
    
- 局内融合后技能表现同步更新。
    
- 战斗结束后临时效果和事件正确清除。
